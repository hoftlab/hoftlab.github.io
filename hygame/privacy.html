상상 놀이터 개인정보처리방침

운영자: HoftLab · 적용일: 2026년 10월 29일 · 앱: com.hoftlab.kidsplay

상상 놀이터는 회원 가입 없이 기기 안에서 즐기는 어린이 놀이 앱입니다. 앱은 아이의 그림과 학습 기록을 개발자 서버로 보내지 않으며, 광고·분석 SDK를 사용하지 않습니다.

1. 앱에서 처리하는 정보

그림과 색칠 내용, 작품, 놀이 진행, 별·스티커, 학습 시간·정답 및 오답 기록, 소리 설정은 기능 제공과 이어하기를 위해 기기 안에 저장합니다. 이름·생년월일·주소·연락처·위치·광고 식별자를 요청하지 않습니다. 카메라·마이크·연락처 접근 기능도 없습니다.

2. 외부 전송과 제3자 제공

현재 Android 앱은 인터넷 권한이 없으며 앱 내 놀이 정보를 운영자나 광고·분석 업체에 전송하지 않습니다. 운영자는 기기에 저장된 그림·학습 기록에 접근할 수 없습니다. 기기 운영체제의 백업·복원은 이용자의 Android 설정 및 해당 서비스 정책에 따라 이루어질 수 있으며, 운영자가 직접 제공하는 클라우드 동기화는 없습니다.

3. 가족·지인 무료 초대

앱은 설치별 무작위 요청 번호와 검증된 해제 키를 기기에 보관합니다. 요청 번호는 기기의 하드웨어 식별자, 아이의 이름이나 학습 기록을 포함하지 않습니다. 보호자가 무료 초대를 요청하는 경우에만 직접 요청 번호를 개발자에게 전달하며, 앱이 자동 전송하지 않습니다. 요청 번호와 해제 키는 Android 백업·기기 이전 대상에서 제외됩니다.

4. 보호자의 문의

보호자가 이메일로 문의하면 이메일 주소, 직접 적은 문의 내용 및 전달한 요청 번호를 응대와 키 발급에 사용합니다. 아이의 이름·사진·학습 기록을 보내실 필요는 없습니다. 문의 해결 후 불필요한 정보는 삭제하며, 별도 보관이 필요한 요청은 목적과 기간을 보호자에게 안내합니다. 문의 정보의 삭제도 아래 이메일로 요청할 수 있습니다.

5. 보관과 삭제

앱의 부모 메뉴에서 학습 기록을 삭제할 수 있습니다. 모든 로컬 그림·설정·초대 권한을 지우려면 Android 설정에서 이 앱의 데이터를 삭제하거나 앱을 제거하세요. 운영체제 백업에 남은 데이터는 해당 백업 서비스 설정에서 관리합니다. 앱 데이터 삭제나 새 기기로의 변경 후에는 초대 키 재발급이 필요합니다.

6. 아동 보호

아동의 개인정보를 가입이나 놀이의 조건으로 요구하지 않습니다. 구매·초대·기록 관리 등 보호자 기능은 부모 확인 뒤 이용합니다. 문의와 초대 요청은 보호자가 진행해 주세요. 운영자는 아동의 개인정보를 광고, 추적 또는 판매 목적으로 사용하지 않습니다.

7. 결제와 변경 안내

현재 버전은 무료 체험 콘텐츠와 무료 초대 기능을 제공하며 유료 결제·구매 복원은 준비 중입니다. 향후 스토어 결제를 연결하거나 정보 처리 방식이 달라지면 배포 전에 이 방침과 앱 안내를 갱신합니다.
