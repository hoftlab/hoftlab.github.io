# GIF Studio sticker library

3D stickers the GIF Studio app (com.hoftlab.gifmaker) downloads on demand and keeps on the phone.

Pictures are **Fluent Emoji** by Microsoft (https://github.com/microsoft/fluentui-emoji, commit 1ffb34c), used under the
**MIT License** — the full notice is in [LICENSE](LICENSE). The 256 px `3D` PNGs were converted to WebP
(`cwebp -q 82 -alpha_q 90 -m 6`) and renamed; nothing else was changed.

`catalog.json` lists every file with its size and SHA-256 (the app checks both), the app tab it belongs to and the loop
motion it starts with (`float`, `pulse`, `wiggle`, `spin`).
